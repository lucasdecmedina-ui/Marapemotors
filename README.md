# Marapé Motors

Site institucional responsivo do centro automotivo Marapé Motors, em Santos.

Abra `index.html` para visualizar. Para publicar, use a raiz deste repositório como diretório do site estático.

Inclui serviços, sobre, mascote em três poses, formulário de orçamento pelo WhatsApp, Instagram e localização no Google Maps.

As imagens ilustrativas dos serviços foram geradas para o site. Fontes e mapa precisam de conexão com a internet.
